# Calendar feeds

You can see your Offing birthdays in the calendar app you already use (Apple Calendar, Google Calendar or Outlook) by subscribing to a private link.

## Getting a link

1. Go to **Settings → Connected apps**.
2. Give the link a name, such as "My iPhone", and choose **Create link**.
3. Copy the link straight away, or use **Add to Apple Calendar** or **Add to Google Calendar**. For security, Offing only shows each link once.

Each birthday appears as an all-day event every year. In Apple Calendar you'll also get two reminders: one at 8pm the evening before and one at 8am on the day. Google Calendar doesn't show reminders from subscribed calendars.

Calendar apps check for changes on their own schedule, so a new or edited birthday can take a while to appear. Google can take up to a day.

If someone's birthday is on 29 February, it shows on 28 February in years that aren't leap years.

## Keeping links safe

Anyone who has a link can see every birthday in it, so treat it like a password. You can have up to three links at once. Give each device or account its own link, so you can switch one off without affecting the others.

The list in Settings shows when each link was last used. If you've lost a link or think someone else has it, revoke it. Any calendar using that link stops updating straight away. Then create a new link.
